# 回款雷达

面向个人自由职业者的轻量应收款跟进工具。它帮助你记录应收、安排跟进、登记到账，并在首页聚焦今天真正需要处理的款项。

## 使用方式

直接双击 `index.html` 可以查看页面；若需要完整使用备份下载等浏览器功能，建议在项目目录运行：

```powershell
python -m http.server 4173
```

然后在浏览器打开：

```text
http://localhost:4173
```

## 核心流程

1. 新建应收：填写客户、项目、金额和付款截止日。
2. 在“今日行动”处理承诺付款日已过、逾期、已到跟进日或当天到期的记录。
3. 在详情中记录沟通结果，填写客户承诺付款日和下次跟进日。
4. 登记部分或全部到账；全额到账后记录自动标记为“已收款”。
5. 需要时生成催款文案，复制后自行通过微信、邮件或其他渠道发送。

## 数据与备份

- 数据仅保存于当前浏览器的 LocalStorage，不会上传云端。
- 请定期使用首页“导出备份”保存 JSON 文件。
- 更换设备、清理浏览器数据或使用无痕模式前，应先导出备份。
- 恢复备份会合并新记录；相同 ID 的记录会跳过，错误文件不会覆盖现有数据。
- 不要在备注中录入银行卡号、身份证号、密码或其他敏感信息。

## 日历提醒

在应收详情的“催款文案”窗口，可导出付款截止日或下次跟进日的 `.ics` 文件，再导入自己的日历应用。

## 测试

项目不依赖外部测试框架，运行：

```powershell
npm test
```

测试覆盖状态计算、金额校验、今日行动、到账、跟进、本地存储、JSON 备份恢复、催款文案和日历导出。

## MVP 边界

当前版本不包含账号、云同步、多设备协作、自动发送消息、支付、发票开具、复杂报表或客户管理功能。
