# 回款雷达

面向个人自由职业者的轻量应收款跟进工具。它帮助你记录应收、安排跟进、登记到账，并在首页聚焦今天真正需要处理的款项。

## 本地界面预览

直接双击 `index.html` 可以查看页面；若需要完整使用备份下载等浏览器功能，建议在项目目录运行：

```powershell
python -m http.server 4173
```

然后在浏览器打开：

```text
http://localhost:4173
```

## 核心流程

1. 新建应收：填写客户、项目、金额和付款截止日。
2. 在“今日行动”处理承诺付款日已过、逾期、已到跟进日或当天到期的记录。
3. 在详情中记录沟通结果，填写客户承诺付款日和下次跟进日。
4. 登记部分或全部到账；全额到账后记录自动标记为“已收款”。
5. 需要时生成催款文案，复制后自行通过微信、邮件或其他渠道发送。

## 数据与备份

- 登录后，应收、到账和跟进记录保存在账号对应的 PostgreSQL 云端数据中，电脑和手机使用同一账号即可同步。
- 页面打开和手动刷新会从云端读取最新数据；网络失败时不会把操作显示为已保存。
- “导出备份”仍可下载 JSON；首次导入旧浏览器数据前会先下载原始备份。
- 导入时同 ID 的云端记录优先保留，重复项会跳过；更换设备或清理浏览器前仍建议先导出备份。
- 不要在备注中录入银行卡号、身份证号、密码或其他敏感信息。

## 云端账号与部署

当前版本已加入邮箱注册、邮箱验证、登录、退出、密码重置，以及应收记录的云端存储和多设备同步。账号、会话和业务数据保存在 PostgreSQL；云端为正式数据源。

生产方案使用 Docker Compose 运行 Caddy、Fastify API、PostgreSQL 和加密备份服务。详细部署、检查、恢复演练、升级及应急操作见 [`docs/operations/cloud-runbook.md`](docs/operations/cloud-runbook.md)。复制 `.env.example` 后必须替换所有示例值，真实密码、邮件凭证、COS 密钥和备份文件不得提交 Git。

## 日历提醒

在应收详情的“催款文案”窗口，可导出付款截止日或下次跟进日的 `.ics` 文件，再导入自己的日历应用。

## 测试

项目不依赖外部测试框架，运行：

```powershell
npm test
```

测试覆盖状态计算、金额校验、今日行动、到账、跟进、本地存储、JSON 备份恢复、催款文案和日历导出。

## MVP 边界

当前阶段不包含多人协作、自动发送消息、支付、发票开具、复杂报表、客户管理、PWA/Android 打包或应用商店发布。单人账号的电脑/手机网页登录和云端同步已包含在 MVP 内。
