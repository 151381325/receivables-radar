# 第二项验收：同一表单保存中的重复提交

日期：2026-10-14。范围：生产网页构建、隔离内存API和示例记录，不连接正式账号。

命令：`node scripts/ui-smoke.mjs --dist --duplicate-save-acceptance`。

## 方法与结果

分别在1440px桌面和390px移动尺寸下验证新增应收、登记到账、保存跟进，共6组。

- 每组连续10次DOM按钮click，再派发10次submit事件。
- 测试API暂缓处理写入，直到检查完成才放行；不依赖固定延迟恰好覆盖请求。
- 每组只收到1个写请求；等待期间服务器示例记录不变。
- 保存按钮禁用并显示“请稍候…”。
- 放行后，新建仅增加1笔应收；到账仅增加1条且金额1元；跟进仅增加1条；版本分别递增一次。
- 结束后表单控件恢复。6组全部通过，无页面未处理异常。
- 表单防重复提交单元测试2项通过；上一项断网验收与普通UI smoke复验通过；git diff --check通过。

首次测试因新断言误用payments而非既有paymentRecords字段停止；核对domain.js后只修正测试字段为paymentRecords和followUpRecords，未修改产品逻辑，完整重跑通过。

## 边界

本项证明同一页面正在保存时的防连点，不代表网络响应丢失后重试、新开页面或多设备提交具有全局幂等性。未在正式手机账号进行写入测试；没有提交、推送、部署或改变正式业务数据。
