# 回款雷达 APP 真机验收与发布检查单

当前状态：新版代码位于 codex/fintech-core-improvements。2026-10-14 发布前重新运行146项自动化测试，全部通过、无跳过；浏览器模拟手机尺寸回归通过。已连接 HONOR300Pro / Android16，独立测试包已验证原生 JSON/ICS 保存和取消。用户已授权正式签名、代码推送及网站部署；生产部署仍需服务器通道。

## 测试环境边界

- 手机已安装的正式 APP 加载线上网站；线上网站尚未更新，所以当前正式 APP 不能用于验收本轮新增网页功能。
- 先连接手机，验证现有原生容器的文件保存、导入、复制、返回和启动行为；新版功能应在隔离测试站点/测试包上验收，不能把旧版测试结果当作新版通过。
- 测试包不得覆盖正式签名密钥、图标或备案元数据。若需要安装/升级正式包，先核对包名、签名与版本；卸载或清除数据需单独确认。
- 采用专用测试账号与示例客户，不发送催款消息，不处理真实支付，不批量修改真实记录。

## 连接手机

1. 手机启用开发者选项与 USB 调试。
2. 用支持数据传输的 USB 线连接电脑。
3. 手机解锁，在调试授权提示中允许这台电脑。
4. ADB 状态为 device 后才能开始；unauthorized 表示尚未授权，offline 表示连接异常。

## 发布准备

1. 复核拟提交文件，只包含本轮实现、必要资源、迁移与测试，排除旧方案文档、临时文件与截图产物。
2. 用户已明确授权正式签名 APK、提交推送与网站部署；未授权卸载、清除数据或商店上传。
3. 服务器先确认工作区改动与当前版本，保存部署前数据库备份并验证可恢复。
4. 构建新 API 与 web 镜像。API 当前会在开始监听前自动执行 runMigrations；004新增承诺动作及事件顺序，005新增到账纠错审计表。
5. 先更新 API 并等待健康，再更新 web；不重建/清空数据库服务或数据卷。
6. 核对健康接口、登录、权限接口、迁移记录和网页资源，再在手机正式 APP 验证。
7. 新增迁移为前向扩展，保留旧列；应用回滚也必须核对兼容性，不执行生产数据覆盖恢复。

本文件为准备与验收记录，不代表手机验收或服务器部署已完成。
