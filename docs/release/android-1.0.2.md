# Android 1.0.2 发布说明

- versionCode：3；包名与桌面名称、已备案图标保持不变。
- 使用原有正式签名配置构建；覆盖升级，不卸载、不清除数据。
- 返回键优先关闭弹窗；未保存输入先询问，取消后保留；非首页返回今日；保存中阻止返回；仅空闲首页允许退出。
- 网页脚本异常时不误退出。需要同时部署包含 back-navigation.js 的新网页才能使用完整规则。
- 保留备份/日历系统文件保存功能和资源版本化缓存策略。
- 日历默认提醒时间兼容性按用户决定暂停，仅增加核对提示，原日历导出算法未改变。

## 发布验收边界

自动化与隔离真机测试不替代正式账号验收。云服务器通过用户Ubuntu终端仅更新web，不改API/数据库。安装后需确认版本1.0.2、账号与原记录保留、弹窗返回及未保存输入取消行为。
