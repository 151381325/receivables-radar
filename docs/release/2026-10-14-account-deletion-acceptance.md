# 自助账号注销：本地实现与隔离验收

日期：2026-10-14。状态：本地实现完成，未提交、推送或部署，未删除正式账号。

## 功能与边界

- 我的账号提供注销入口，要求当前密码、准确填写“注销”、勾选后果确认。
- 仅允许删除当前登录账号，管理员禁止自助注销；跨站请求拒绝，接口限流。
- 单次数据库事务删除用户及关联在线应收、到账、跟进、重置令牌和全部会话；不影响其他用户。
- 管理审计保留操作与时间，删除账号引用置空。历史备份及用户自行导出的文件不随在线删除即时改写，界面和隐私政策明确说明。
- 成功后清空当前页面私有内容、表单和仓库缓存。旧会话迟到的成功响应与401不能恢复旧数据、重新打开详情或退出新登录账号。
- 客户端请求及服务端API响应均禁止缓存，避免私有数据跨会话缓存和同URL迟到请求阻塞。

## 发布前置条件

1. 发布需要单独授权；需同时更新API和web，只有web更新不足以启用注销接口。
2. API启动自动执行006迁移。先备份并确认备份可恢复，勿手动删除迁移历史。
3. 发布前核实实际备份保留周期、访问控制与过期清理措施；本次未核验生产备份配置，也不宣称历史备份已即时删除。
4. 旧备份恢复前必须核对并重新落实已受理的删除，不能将已注销账号直接恢复上线。
5. 上线后仅用专门测试账号进行真机端到端注销验收；真实账号删除须另获明确授权。

本验收不是全面渗透测试、法律合规认证或应用商店审核保证。
