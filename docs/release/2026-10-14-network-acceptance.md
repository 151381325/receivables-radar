# 第一项验收：断网与恢复

范围：生产网页构建；隔离内存API与合成示例，不连接正式账号。日期2026-10-14。

命令：`npm run build`；`node scripts/ui-smoke.mjs --dist --network-acceptance`。

浏览器1440px桌面、390px移动尺寸全部通过：

- CDP网络层断网，不仅模拟HTTP错误。
- 刷新失败提示同步失败，原金额和记录仍保留。
- 断网提交新建应收，显示网络连接失败；示例服务器记录完全未变。
- 客户、金额、备注仍保留，表单退出忙碌状态，可重试。
- 恢复网络后重新提交，只创建一条示例记录。
- 重试同步后恢复已同步状态。

随后普通生产构建UI smoke也通过。仅扩展测试脚本，没有修改产品代码，没有提交推送或部署。

尚未覆盖：请求已经提交但响应丢失；长时间超时；断网后重启APP；正式APP内断网提交真实记录。不能将本报告理解为完整离线使用能力已通过。
