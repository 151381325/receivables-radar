# Android 返回键修复（本地验证完成，尚未发布）

## 需求与边界

用户真机确认：键盘收起后，在催款文案弹窗按返回会直接退出APP。用户批准以下规则：弹窗优先关闭；未保存表单先确认；应收/我的返回今日；只有今日且无弹窗时才允许退出。

不修改既有应收、到账、日历事件或登录数据，不改包名、图标、密钥或生产环境配置。初次验证未发布；用户随后批准继续生成1.0.2同签名正式APK、推送代码和部署网页，禁止卸载或清除APP数据。

## 实现

- 网页 `src/back-navigation.js` 定义返回决策；app.js提供当前页面、弹窗顺序、输入基线和保存状态。
- 未保存输入选择取消时保留原页面与文字；选择放弃才关闭或返回。不在返回过程中保存业务数据。
- 正在提交时消费返回，不中断状态显示。
- Android MainActivity使用AndroidX返回回调，调用固定网页处理入口；仅信任既有正式域名或明确启用的独立测试地址。
- 只有网页明确返回布尔false才允许原生回退。脚本异常、非布尔值不误退出；15秒无响应会解除等待并提示重试，迟到回调忽略。
