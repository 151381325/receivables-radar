# 第五项验收：账号安全与注销流程（部分通过）

日期：2026-10-14。仅对隔离账号执行安全请求；正式手机只读查看入口和政策，没有退出、重置密码、注销、删除数据或发邮件。

## 安全测试通过

新建独立PostgreSQL库radar_security_test，使用生产路由和真实会话验证：

- 未登录读取当前用户、应收与管理汇总均401。
- B账号无法列出A记录；已知A记录ID时，编辑、到账、跟进、删除请求均404，A数据未改变。
- 普通用户管理接口403。
- 过期会话401；退出后原会话访问应收401，不影响B会话；Cookie具备HttpOnly、Secure与SameSite=Lax。
- 既有真实数据库登录/重置/注册/管理员/会话专项共23项通过，包括重置密码使全部旧会话失效、令牌重复和过期拒绝、未验证或禁用账号无法登录、注册限流。
- 完整npm test：158通过，0失败，0跳过。测试邮件仅由本地替身收集，没有真实发送。
